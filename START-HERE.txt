IMPORTANT LIMITS

PUTTING THE PORTAL ON THE INTERNET (read this first)
============================================================
The portal only works with the secure server; opened as a plain file it shows no data and no login.

For real use, run the secure server in the folder "4-secure-server". It stores passwords hashed, gives every person only the data
they may see, locks accounts after repeated wrong passwords, hides the Google secret and sets security headers.
Instructions: 4-secure-server/README.md   (needs a Linux server with Docker, a domain name and HTTPS).
The security audit is in SECURITY-AUDIT-REPORT.md (section 12 describes the server and what is still limited).

EMPLOYEE LOGIN ADDRESS (secure server): https://your-domain/access/employee-server  (you can change it with STAFF_PATH). Give it only to employees.
